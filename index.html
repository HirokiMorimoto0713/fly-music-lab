01

配線は実物から

MaleCNSはオスのショウジョウバエの神経の接続を再構築したデータです。このアプリでは、Xenovaが抽出した166,700神経と25,582,938接続をすべて読み込みます。神経の「振る舞い」は次の数式で仮定します。

02

刺激がたまると発火する

LIFモデルでは、神経の電位が時間とともに静かな状態に戻り、入力が重なると上がります。閾値を超えると発火し、接続先へ信号が届きます。0.1 msずつ計算します。刺激には再現できる乱数を使うので、シードも実験条件のひとつです。

刺激 → 電位の変化 → 発火 → 接続先へ
03

音と動きは私たちの翻訳

5つの神経集団それぞれの発火数を、選んだ音階の5音に変換します。集団が発火したら音を鳴らし、発火数から音程と強さを決めます。歩行や旋回も、選んだ下行性ニューロンの発火率を速度に変えるルールです。ハエが音階を知っているわけではありません。

具体的な変換式

音階の位置 = (集団番号 + floor(3 × log₂(1 + 発火数))) mod 5。音の強さ = min(105, 32 + round(7 × log₂(1 + 発火数)))。視覚の回路は1オクターブ上。他の4集団は低い音域です。歩行はDNp09 / DNg100 / DNg97、旋回はDNa02 / DNa11 / DNg13の左右差、羽はDNp01を読み取ります。身体から脳への感覚フィードバックはありません。

04

ひとつだけ変えて比べる

同じシードで再実行して同じフレーズになるかを確認。次に伝播を止めて、活動の広がりを比較します。音階だけを変えると、配線を変えずに同じ活動を別の音楽として聴けます。こうして原因を切り分けるのが実験の基本です。
