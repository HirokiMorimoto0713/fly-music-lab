## 実ブラウザ

Chrome / Playwrightで実データを用いたE2Eを実施。テスト実装: `tests/browser.mjs`。

```sh
PLAYWRIGHT_MODULE=/home/motoha/.ai-agent-shared/node_modules/playwright node tests/browser.mjs
```

このパスは母艦の既存Playwrightです。別環境ではインストール済みのplaywrightのパスを指定してください。製品ランタイムにはPlaywrightは不要です。

- 全配線ロード → 開始 → 左・右・LC4刺激 → 12ステップ → 停止
- 60音を生成。累計35,221発火
- MIDIダウンロード、同じ条件で再実行したMIDIがバイト単位で一致
- WAV合成: 171,760 bytes、16bit PCMピーク5258。無音でもクリップでもない
- JSONダウンロード → 読み込み → 再計算したMIDIもバイト単位で一致
- ブラウザ保存がページ再読み込み後も存在
- 伝播比較: あり35,221発火 / なし9,454発火。左・右の直接刺激を含むため、伝播なしでも下行性の発火は残る
- 停止後に表示のステップ数と発火数が増えない
- 不正JSONは明示的に拒否。データ404は準備コマンドを表示し、同じページから再試行して復旧
- 320 / 390 / 768 / 1280pxで横はみ出しなし。1280×800で開始操作が画面内
- 日本語のガイドとモデル説明がHTTP 200
- pageerrorなし

追加の `tests/lifecycle.mjs` も合格。準備中に停止しても前の実験のシードを保持、刺激0 Hzで音符0・音声書き出し無効、通常の128ステップを最後まで実行して自動終了を確認しました。全長の実行では101,326発火・605音でした。

`artifacts/` に実行結果JSON、WAV、MIDI、実験JSON、スクリーンショットを保存（Git対象外）。視覚点検ではPCの実験画面、保存欄、実習欄、モバイル画面を確認。全ページスクリーンショットはリサイズ直後にChromeの描画欠落が出たため、保存欄と実習欄はスクロール後の実画面も別に撮影・点検しました。

## メロディー模倣と3Dの追加検証（2026-09-11）

`npm test` — 6件合格。既存4件に加え、メロディーの入力・採点と、実配線の読み出し学習・推論境界・対照条件を検証しました。

| 条件 | 音程の一致 | 長さの一致 | 解釈 |
| --- | --- | --- | --- |
| 固定8曲・練習と同じシード1 | 各100% | 各100% | 学習例への適合 |
| のぼる・シード2 | 33% | 100% | 違う刺激乱数への対応は弱い |
| 未学習のシ・ド（長い）・ファ、シード2 | 0% | 0% | この例では応用できなかった |
| のぼる・伝播なし | 0% | 0% | 入力群以外の特徴はゼロ、返事は無音 |
| のぼる・聴いたあとに状態をリセット | 0% | 0% | 特徴はゼロ、返事は無音 |

特徴量ゼロ時は無音にする明示的な規則があります。したがってリセット対照の無音だけを、生物学的記憶の証明と解釈しません。全配線の重みが学習の前後で不変、同じシードと入力で特徴が一致、正解を渡さない推論関数の出力が採点対象によらない、保存した係数で出力が一致することも検証しました。成果物は `artifacts/echo-model-results.json`。

### Chromeでの実操作

`tests/echo-browser.mjs` を既存のPlaywrightとPC版Chromeで実行します。

```sh
PLAYWRIGHT_MODULE=/home/motoha/.ai-agent-shared/node_modules/playwright node tests/echo-browser.mjs
```

- WebGLで立体のハエ・ヘッドフォンを表示。角度変更で描画が変化
- お手本試聴、音付き練習の中断、鍵盤入力・音の長さ変更
- 全配線ロード、8曲の学習、復習の一致率、返事の再生
- シード2・伝播なし・状態リセットの比較
- MIDI / WAV / 実験JSON / ノートを書き出し。WAVは無音でもクリッピングでもない
- ページ再読み込みとノートインポートで学習を復元
- 未学習曲が「未学習」と表示され、勝手に学習へ追加されない
- 中断しても前の学習を保持。お手本が編集中の0音でも再読み込みで学習を失わない
- 不正ノートを拒否し、既存学習を保持
- データ404時のエラー表示と同一ページでの再試行・復旧
- 3Dモジュールが使えない場合も、実配線の練習を完了できる
- 幅320 / 390 / 768 / 1280で横はみ出しなし、pageerrorなし

以前の自由演奏に対する `tests/browser.mjs` も `/free.html` を使って再実行し、全エクスポート・再現性・対照・復元・欠落データ復旧を確認しました。移動後のルートをテストで修正した以外は、元の合格条件を維持しています。
